<threat_model>
Potential threats:
- Shell injection or path breakage if command strings are used.
- Sensitive path/password leakage in logs in later phases.
- UI crash on missing executable or non-zero process exit.

Required mitigations:
- Use `Process.executableURL` and `Process.arguments` only.
- Do not invoke `/bin/sh`, `zsh`, or `bash`.
- Return structured process results and typed/user-readable errors.
- Do not add password support in Phase 1.
</threat_model>
