# Structure

## Summary

The repository is a compact Xcode project with one SwiftUI app target.
Most directories are generated by Xcode or GSD tooling.
Application code is currently limited to two Swift files under `Qizip/`.

## Top-Level Layout

- `Qizip.xcodeproj/` — Xcode project metadata and workspace.
- `Qizip/` — SwiftUI app source and assets.
- `.codex/` — Codex/GSD agent, skill, hook, and workflow support files.
- `.claude/` — Claude/GSD agent, hook, and workflow support files.
- `.github/` — GitHub Copilot/GSD agent and instruction files.
- `.git/` — local git repository metadata.

## App Source Layout

- `Qizip/QizipApp.swift` — app lifecycle entry point.
- `Qizip/ContentView.swift` — placeholder root SwiftUI view.
- `Qizip/Assets.xcassets/Contents.json` — asset catalog metadata.
- `Qizip/Assets.xcassets/AccentColor.colorset/Contents.json` — accent color metadata.
- `Qizip/Assets.xcassets/AppIcon.appiconset/Contents.json` — app icon metadata.

## Xcode Project Layout

- `Qizip.xcodeproj/project.pbxproj` — target, build settings, platform settings, signing settings.
- `Qizip.xcodeproj/project.xcworkspace/contents.xcworkspacedata` — workspace metadata.
- `Qizip.xcodeproj/xcuserdata/cloud.xcuserdatad/xcschemes/xcschememanagement.plist` — user-specific scheme metadata; this is typically not important for product architecture.

## Naming Conventions Present

- App module and target use `Qizip`.
- SwiftUI app type is `QizipApp`.
- Root placeholder view is `ContentView`.
- Asset catalog uses standard Xcode names: `Assets.xcassets`, `AccentColor`, `AppIcon`.

## Generated Tooling Directories

The repository contains GSD support files across `.codex/`, `.claude/`, and `.github/`.
These are workflow/tooling assets, not application runtime code.
Planning output is expected under `.planning/`.

## Current Missing Product Structure

No directories exist yet for:

- Models
- Services
- Views beyond `ContentView`
- View models
- Tests
- Resources/bundled binaries
- Scripts
- Documentation
- CI workflows

## Structure Guidance For Future Work

For a macOS archive app, avoid letting `ContentView.swift` become the product.
Introduce feature folders when behavior appears, for example:

- `Qizip/App/`
- `Qizip/Features/ArchiveBrowser/`
- `Qizip/Features/Operations/`
- `Qizip/Core/Archive/`
- `Qizip/Core/SevenZip/`
- `Qizip/Core/FileAccess/`
- `Qizip/Resources/`
- `QizipTests/`

This guidance reflects the expected product shape; it is not yet implemented.
